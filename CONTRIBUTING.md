# Contributing to KitsuneSU

Thank you for your interest in contributing to **KitsuneSU**! We welcome community contributions, bug reports, and suggestions.

## 🦊 How to Contribute

### Reporting Bugs
If you encounter a bug, boot issue, or crash:
1. Check existing [Issues](https://github.com/Komarku/KitsuneSU/issues) to avoid duplicates.
2. Open a new issue using our **Bug Report** template.
3. Provide:
   - Device model & SoC
   - Android version & Kernel version (`uname -r`)
   - Installation method (`init_boot` or `boot` / Kitsunepatch)
   - Logcat / `dmesg` logs if available.

### Submitting Pull Requests
1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-feature-name`.
3. Test your changes locally before submitting.
4. Ensure clean code formatting.
5. Push to your fork and submit a Pull Request targeting the `main` branch.

### Feature Suggestions
Have an idea for a new feature or improvement? Open an issue with the **Feature Request** label.
